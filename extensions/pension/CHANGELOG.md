# Changelog

## 2.0 — Pension member retention

Rebuilt the telecom benchmark as an explicitly synthetic pension-fund project to match the supplied goal and two tasks. Added a 90-day voluntary full-transfer target, per-member potential withdrawal, probability-weighted outflow, separate fee-revenue exposure, a flagged-member export and retention priority queue. Added embargoed temporal evaluation, a transparent data generator, schema validation, recruiter-focused documentation and GitHub Actions workflows. Prior telecom results and assets are absent from the active repository; their metrics must not be used for this version.
